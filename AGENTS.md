# Repository purpose

Hands-on AZ-104 and AZ-305 learning.

# Working conventions

- Keep each lab independently deployable and disposable.
- State command working directories.
- Explain expected results and verification.
- Distinguish observed behavior from assumptions.
- Prefer official documentation for technical claims.
- Never commit credentials, Terraform state, or saved plans.
- Commit Terraform provider lock files.
- Document costs and cleanup before deployment.
- Do not create shared abstractions until repetition justifies them.
- Update lesson documentation when behavior changes.
- Treat AWS comparisons as analogies, not exact equivalence.
- Do not deploy resources merely to edit documentation.
